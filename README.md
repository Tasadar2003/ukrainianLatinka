# Ukrainian - Latynśki

**Ukrainian - Latynśki** — клавіатурна розкладка для української мови на основі латинського алфавіту та стандартної QWERTY-розкладки.

Проєкт розроблений у межах **Atlantus Future System (AFS)**.

## Походження проєкту

Проєкт базується на первинній концепції української латиниці, опублікованій виданням [**«На часі»**](https://nachasi.com/manifest/).

Первинна концепція та її основна система належать відповідному автору. **Atlantus Future System не претендує на авторство первинної концепції.**

Власний внесок **Atlantus Future System** полягає у:

- створенні концепції позначення пом'якшених приголосних;
- додаванні відповідних латинських символів із діакритиками;
- технічній реалізації розкладки для Linux через XKB;
- реалізації спеціальних клавішних комбінацій через AltGr;
- інтеграції розкладки до системи XKB rules;
- тестуванні розкладки в реальному Linux-середовищі.

Таким чином, **Ukrainian - Latynśki** поєднує первинну концепцію української латиниці «На часі» з розширенням та технічною реалізацією **Atlantus Future System**.

---

## Мета

Метою проєкту є створення практичної української латинської клавіатурної розкладки для Linux, яка:

- використовує стандартну QWERTY-структуру;
- зберігає звичне розташування базових латинських літер;
- підтримує спеціальні українські символи;
- має окреме позначення пом'якшених приголосних;
- використовує диграфи для окремих українських літер;
- не займає стандартні Ctrl-комбінації;
- інтегрується зі стандартною системою XKB.

# Розкладка

## Основні літери

Базові латинські літери відповідають клавішам стандартної QWERTY-розкладки.

```text
Q W E R T Y U I O P
 A S D F G H J K L
  Z X C V B N M
```

Регістр змінюється стандартним `Shift`.

---

# Позначення пом'якшень

Окремою частиною розширення **Atlantus Future System** є система позначення пом'якшених приголосних.

Для цього використовуються латинські літери з діакритичними знаками:

| Українська | Latynśki |
|---|---|
| Дь / дь | Ď / ď |
| Зь / зь | Ź / ź |
| Ль / ль | Ĺ / ĺ |
| Нь / нь | Ń / ń |
| Сь / сь | Ś / ś |
| Ть / ть | Ť / ť |
| Ць / ць | Ć / ć |

Ця система **не входила до первинної концепції**, на якій базується проєкт, і є власним концептуальним доповненням **Atlantus Future System**.

# Диграфи

Для окремих українських літер використовуються послідовності двох латинських символів.

| Українська | Latynśki |
|---|---|
| Є / є | Je / je |
| Щ / щ | Šč / šč |
| Ю / ю | Ju / ju |
| Я / я | Ja / ja |

Диграфи вводяться як звичайна послідовність символів.

```text
Je → Є
je → є

Šč → Щ
šč → щ

Ju → Ю
ju → ю

Ja → Я
ja → я
```

# Ctrl-комбінації

Проєкт **не використовує Ctrl-комбінації для введення спеціальних літер**.

Це зроблено для того, щоб не займати стандартні системні та програмні комбінації:

```text
Ctrl+C
Ctrl+V
Ctrl+X
Ctrl+Z
Ctrl+S
Ctrl+A
```

Спеціальні символи розкладки використовують **AltGr**.

# XKB

Розкладка реалізована як варіант української XKB-розкладки:

```text
layout:  ua
variant: latynski
```

Назва у графічному інтерфейсі:

```text
Ukrainian - Latynśki
```

Основний файл:

```text
xkb/symbols/ua
```

Реєстрація варіанту:

```text
xkb/rules/evdev.xml
xkb/rules/evdev.lst
```

### Базова розкладка та AltGr

Для збереження стандартних цифр і пунктуації використовується:

```text
include "us(basic)"
```

Для активації третього та четвертого рівнів через Right Alt використовується:

```text
include "level3(ralt_switch)"
```

Відповідно:

```text
AltGr       → Level 3
AltGr+Shift → Level 4
```

Це дозволяє не дублювати цифровий ряд та стандартну пунктуацію безпосередньо у `latynski`.

Файл `ua` є текстовим UTF-8 файлом без розширення. Це відповідає структурі системних XKB symbols.

# Встановлення

## Ручне встановлення

Скопіювати XKB symbols:

```bash
sudo cp xkb/symbols/ua /usr/share/X11/xkb/symbols/ua
```

Додати варіант `latynski` до:

```text
/usr/share/X11/xkb/rules/evdev.xml
/usr/share/X11/xkb/rules/evdev.lst
```

Після цього у налаштуваннях клавіатури вибрати:

```text
Ukrainian
└── Ukrainian - Latynśki
```

> **Примітка:** системні файли XKB можуть бути перезаписані під час оновлення пакета `xkeyboard-config`. Перед оновленням системи рекомендується зберігати резервну копію змінених файлів.

# Перевірка

Перевірити компіляцію XKB можна командою:

```bash
xkbcli compile-keymap --layout ua --variant latynski
```

Для інтерактивного тестування:

```bash
xkbcli interactive-evdev --layout ua --variant latynski
```

Також рекомендується перевірити:

```text
1234567890
!@#$%^&*()

ťďğїćśšžźčĺń
ŤĎĞЇĆŚŠŽŹČĹŃ
```

# Сумісність

Поточна реалізація орієнтована на Linux-системи, що використовують XKB.

Розкладка протестована на:

- **Manjaro Linux**
- **KDE Plasma / Wayland**
- **GNOME / Wayland**
- **xkeyboard-config**

Розкладка використовує стандартні механізми XKB і не є окремим драйвером клавіатури.

# Поточний статус

**Version: 1.0.1**

**Status: Stable**

Версія `1.0.1` містить виправлення сумісності для середовищ, у яких `Right Alt` не визначався автоматично як `Level3`.

До variant `latynski` додано:

```text
include "level3(ralt_switch)"
```

а базова клавіатура успадковується через:

```text
include "us(basic)"
```

Це забезпечує коректну роботу:

- стандартного QWERTY;
- цифр;
- пунктуації;
- `AltGr`;
- `AltGr + Shift`;
- спеціальних символів.

Розкладка успішно протестована у **KDE Plasma** та **GNOME** на Wayland.
